# gezi-life
# 格子人生
> 📊伪装成Excel表格的0成本网页模拟人生游戏，GitHub Pages直接游玩。
按键盘`Esc`一键切换财务审计报表摸鱼。

## 🎮特性
- 随机投胎系统：出生地、家庭阶层开局随机
- 日历格子模拟每一天人生，手动点格子 / 🎲命运骰子快进时间
- 本土化现实事件库：新生儿黄疸、幼儿园霸凌、中考普职分流、996加班、35岁裁员、父母重病
- 情绪治愈彩蛋：遭遇悲伤事件触发全屏流星雨动画
- 本地存档：支持导出/导入存档，**所有数据保存在浏览器，不上传任何服务器**
- 终局审计报告，复盘你完整的一生

## 部署方式
1.Fork或者上传全部文件到github仓库
2.仓库Settings→Pages，部署来源选择main分支根目录
3.等待1‑2分钟，得到在线游玩地址

> 本项目 MIT开源，仅为虚构模拟游戏，不代表现实价值观。
